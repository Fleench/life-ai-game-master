# Game Master App

## Project Overview
The Game Master app is a cross-platform application built with an Avalonia UI. The architecture includes an Android headless Binder service, local SQLite synchronization powered by vector clocks, a REST API, and a fully featured .NET client library.

## Final Status
All foundational scaffolding, background services, and automated tests are 100% complete! However, the Android UI port is unfortunately blocked by a persistent `Theme.AppCompat` crash on launch. Because of this and surrounding copyright constraints, we are wrapping up development here.
